All of the shell files work on the distros in the file name and their deriatives (e.g. Fedora from rhel)

The shell scripts include:

A WM (Niri) with DMS
A file manager (Dolphin)
Git
VLC
A browser
Gimp
Libreoffice
Wine
Flatpak
KDE Discover
VSCode
Kitty terminal
OBS

Some distros may get more or less stuff, because the packages may not exist on the package manager of the distro the script is being run on.
